# Getting started

I have just created this directory and started a Vite + React + Typescript project in it. 

The goal of this session is to create a simple website.

You may start with the following assumptions:
- The website will not have any backend, and will be purely frontend. 
- The website will have a simple layout with a header, main content area, and footer.
- Website will include an about page, a contact page, a homepage, a privacy page, and a terms of service page. Fill these pages with dummy content for now.
- Assume professional formatting and styling
- You will use Tailwind CSS primarily for styling
- No emojis unless explicitly requested by the user
- If they ask for a sever/additional functionality, assume that a Express server will be set up to handle that functionality, and you will write the code for that server as well. Place that code in a separate directory called `server` in the project directory.
- Any images should be placeholders. Do not use weblookup for images. The user will go back and replace them manually after initial setup.
